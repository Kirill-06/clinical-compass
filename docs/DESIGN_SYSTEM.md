# Дизайн-система «Клинического компаса»

Код: `lib/core/design/` — `tokens.dart` (цвета, отступы, радиусы, брейкпоинты), `typography.dart`,
`theme.dart` (Material 3 как каркас доступности), `components.dart` (общие компоненты).

## Принципы

1. **Рабочий инструмент, а не витрина.** Первый экран врача — список его пациентов, а не дашборд с метриками.
   Сводка над таблицей — четыре числа, каждое работает как фильтр.
2. **Типографика и разделители вместо карточек.** Белые поверхности с тонкой границей используются только для
   крупных смысловых блоков; внутри — строки с разделителями.
3. **Цвет — только по смыслу.** Зелёный/янтарный/красный применяются к статусам (по графику / требует просмотра /
   просрочено) и всегда дублируются текстом и иконкой. Категории тяжести GAD-7 цветом **не кодируются** —
   интерфейс не делает клинических выводов за врача, полосы шкалы на графике нейтрально-серые.
4. **Демо видно всегда.** Графитовая метка `ДЕМО` / `ТЕСТ` отличается от любых статусных цветов.
5. **Пациенту — одна задача на экран**, спокойный язык без обещаний и драматизации.

## Токены

| Группа | Значения |
|--------|----------|
| Фон / поверхность | `#F6F7F9` / `#FFFFFF`, границы `#DFE3E8`, `#C3CAD3` |
| Текст | `#17212B` основной, `#4F5B67` вторичный, `#66717D` подписи (контраст ≥ 4.5:1 на белом) |
| Акцент | сине-зелёный `#0D5966` (hover `#094651`), подложка `#E3EEF0` |
| Статусы | ok `#1C6A43`/`#E5F2EA`, warn `#83500A`/`#FBF0DC`, danger `#A42619`/`#FBE9E7`, info `#235A8C`/`#E7EFF8` |
| Демо | графит `#29323C` |
| Отступы | сетка 4/8: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64 |
| Радиусы | 6 (кнопки, поля, бейджи), 8 (панели), 10 (диалоги) — без «таблеток» |
| Брейкпоинты | 600 (телефон), 900 (боковая навигация врача), 1060 (полная таблица), 1200 |

Шрифт — системный (SF Pro на Apple, Roboto на Android и в Web), обе гарнитуры с полной кириллицей.
Баллы и даты — моноширинными цифрами (`tabularFigures`), чтобы колонки не «прыгали».
Иконки — единый линейный набор Material (outlined), только там, где помогают распознаванию.

## Компоненты

- `StatusBadge` — текст + иконка + тон; плотный вариант для таблиц.
- `DemoTag` — маркировка демо и тестовых событий.
- `InlineNotice` — уведомление с цветной полосой слева (паттерн NHS inset text / warning callout).
- `Panel`, `SectionHeader`, `KeyValue`, `EmptyState`, `ErrorState`, `LoadingState`.
- `FilterSegment` — сегментированный фильтр со счётчиками.
- `AdherenceStrip` — 7 ячеек приёма препарата с глифами ✓ / × / – (не только цвет) и подсказкой на каждой.
- `ScoreChart` — график шкалы: Y на всю шкалу (0–21), X по реальным датам, подсказка при наведении/касании,
  навигация стрелками с клавиатуры, табличная альтернатива и семантическое описание для скринридера.

## Откуда взяты паттерны

Продукты и дизайн-системы, на которые мы ориентировались (список из ТЗ). Брали подходы, а не внешний вид:
брендинг, логотипы и изображения не копировались.

| Источник | Что взято | Чем отличается наша реализация |
|----------|-----------|--------------------------------|
| Sessions Health — Client List | Левое меню + плотная таблица клиентов, поиск, фильтры, сортировка, кликабельная строка | Колонки под клинический мониторинг: последний/предыдущий GAD-7, разница, check-in, 7-дневная полоса приёма, предметный статус с пояснением |
| Sessions Health — Auto-Scored Assessments | Автоподсчёт шкалы, переход к ответам на каждый вопрос | Ответ хранит версию шкалы и снимок категории; рядом — источник формулировок и пометка о необходимости клинического подтверждения |
| TherapyNotes — Outcome Measures | График по датам с подсказкой и историей измерений | Ось X пропорциональна реальному времени, нет интерполяции, нейтральные полосы категорий, клавиатурная навигация, переключатель «График / Таблица» |
| NHS Design System | Inset/warning-блоки, спокойные статусы, доступные формы, таблицы | Собственная палитра; демо-маркировка отдельным графитовым цветом |
| GOV.UK — Question pages | Один вопрос на экран, «Назад», явная ошибка «Выберите один вариант», страница «Проверьте ответы» с «Изменить» | Прогресс «Вопрос N из 7» и защита от потери ответов/двойной отправки |
| Healthie — client file uploads | Вложения внутри формы, имя/размер, удаление до отправки, передача врачу | Демо-хранилище помечено явно, ограничения форматов и размера, «Открыть»/«Скачать» только при доступном файле |

## Адаптивность

- **Врач:** ≥ 1100 px — боковая панель 248 px (Очередь / Пациенты / Правила); 900–1100 — компактная иконочная
  панель; < 900 — верхняя панель с выдвижным меню. Таблица пациентов: колонки от 980 px, ниже — построчный список.
- **Пациент:** колонка до 640 px по центру; < 900 px — нижняя навигация, шире — ссылки в шапке.
- **Приоритеты очереди** (v0.2): «Срочно» — красная полоса слева и закрепление, «Высокий» — янтарный,
  «Обычный» — синий, «Информация» — нейтральный; всегда текст + иконка. Это порядок работы врача, не
  оценка тяжести состояния.
- Проверено виджет-тестами на 320 / 390 / 768 / 1024 / 1440 px и при двукратном системном шрифте; вручную в
  браузере на 1440 и 390 px.
