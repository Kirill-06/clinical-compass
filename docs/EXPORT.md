# Выгрузка сводки по пациентам

Врач выгружает таблицу по своим пациентам кнопкой «Выгрузить таблицу» в разделе «Пациенты»
(`GET /doctor/exports/patients.csv`). Формат — CSV с разделителем `;` в UTF-8 с BOM: Excel и
LibreOffice открывают его без настройки кодировки.

Таблица **обезличена**: в ней нет ФИО, телефона и текстов сообщений, только ID пациента в сервисе,
год рождения и пол. Каждая выгрузка пишется в журнал аудита пациента (`export.patients_csv`).
Для передачи фармкомпании нужны согласие пациента и договор — см. OPEN_QUESTIONS.md, п. 18.

| Столбец | Что содержит |
|---|---|
| `patient_id` | ID пациента в сервисе (`P-1001`) |
| `birth_year`, `sex` | год рождения, пол |
| `observation_start`, `days_observed` | начало наблюдения и сколько дней прошло |
| `gad7_baseline`, `gad7_last`, `gad7_change` | первый и последний балл GAD-7, изменение от предыдущего (текущий − предыдущий) |
| `phq9_baseline`, `phq9_last`, `phq9_change` | то же для PHQ-9 |
| `phq9_item9_last` | ответ на 9-й вопрос PHQ-9 в последнем опросе (0–3) |
| `adherence_14d_pct` | доля принятых доз за 14 дней, % (слоты без отметки входят в знаменатель) |
| `doses_taken_14d`, `doses_missed_14d`, `doses_unmarked_14d` | принято, пропущено, без отметки за 14 дней |
| `missed_<причина>` | пропуски за всё наблюдение по причинам: `forgot`, `adverse_event`, `felt_unwell`, `ran_out`, `decided_to_stop`, `other`, `unknown` |
| `ae_reports` | всего сообщений о нежелательных явлениях (форма и текст) |
| `ae_in_leaflet` | из них — эффекты из листка-вкладыша |
| `ae_outside_leaflet` | эффекты, которых нет в листке-вкладыше (кандидаты в новые свойства препарата) |
| `ae_affecting_daily_life` | эффекты, которые, по словам пациента, мешают обычным делам |
| `open_alerts_<приоритет>` | открытые события в очереди врача: `info`, `normal`, `high`, `urgent` |

Описания эффектов вне листка-вкладыша (свободный текст пациента) в таблицу не попадают: их врач
видит в разделе «Побочные эффекты» вместе с ID пациента.
