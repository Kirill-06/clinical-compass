# Ветка feature/engagement-ui-pitch-v03 — примечания к ревью

**База:** локальный `main` на коммите `60b3802`. Патч из GitHub ZIP от 27.10.2026 перенесён в отдельный Git worktree с сохранением более новых изменений. Незакоммиченный `.env.example` в исходном рабочем дереве не затронут.

Реализовано:
- Немедицинский 7-дневный индикатор записей, встроенный в пациентский dashboard.
- Flutter-компонент `EngagementCard`, акцент на одном основном действии на главной.
- Мягкая анимация переходов страниц, отключаемая системной настройкой reduce motion; ненавязчивая скрываемая подсказка пациенту.
- Упрощённый текст очереди врача и более заметное объяснение «Почему этот алерт?».
- Готовый исходник презентации: `scripts/build_pitch_v03.js` и PPTX в `docs/presentation`.
- Сопроводительная спецификация и новые backend-тесты.

Не реализовано: push-напоминания, изменение всей дизайн-системы, полноценный клинический пилот, промышленные интеграции ЕМИАС/1С. Не трогали ML/RuleEngine/схему БД.
