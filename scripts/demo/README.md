# Видео Clinical Compass v0.3

Два ролика собираются из кадров работающего локального приложения. `record.js` запускает Chromium через Playwright, входит пациентом и врачом, отправляет демонстрационное сообщение с сигналом риска и открывает карточку в демо-МИС. `build_video.py` добавляет крупные титры и кодирует MP4 через FFmpeg. Исходные снимки, слайды и видео лежат в `artifacts/demo/` и исключены из Git.

## Воспроизведение

Из корня репозитория:

```bash
cd scripts/demo && npm ci && npx playwright install chromium && cd ../..
```

Требуются Flutter web-сборка текущей ветки (`make web`), `backend/.venv` после установки зависимостей проекта, Python с Pillow и FFmpeg. Запустите стенд с отдельной демо-базой в одном терминале:

```bash
rm -f /tmp/clinical-compass-demo-recording.db*
cd backend
CC_DATABASE_URL=sqlite:////tmp/clinical-compass-demo-recording.db \
CC_WEB_DIR=../build/web PYTHONPATH=src \
.venv/bin/python -m clinical_compass.cli serve --port 18080
```

В другом терминале, из корня репозитория:

```bash
CHROMIUM_PATH="$(find "$HOME/.cache/ms-playwright" -path '*/chrome-linux/chrome' -type f | head -1)" \
node scripts/demo/record.js
python3 scripts/demo/build_video.py
python3 scripts/demo/verify.py
```

Если браузер установлен в другом месте, передайте абсолютный путь к исполняемому файлу через `CHROMIUM_PATH`. Адрес стенда можно изменить через `DEMO_BASE_URL`.

## Сценарий

Полная версия, 2:21: вход → «Мой прогресс» и скрываемая подсказка → контроль приёма препарата → форма самочувствия → сообщение врачу → экстренный экран 112/103 → очередь врача → «Почему этот алерт?» → выбор пациента в демо-МИС → карточка внутри медкарты.

Короткая версия, 1:18: вход → «Мой прогресс» → препарат → самочувствие → экстренный экран → очередь врача → объяснение алерта → демо-МИС.

Ролики без звуковой дорожки: пояснения выведены крупными титрами. Все люди и данные в локальном стенде вымышлены. Окно МИС — имитация, а не промышленная интеграция.

`verify.py` проверяет длительность, разрешение и частоту кадров, затем декодирует середину каждой сцены из итогового MP4 в контактные листы и пишет `artifacts/demo/QA_REPORT.md`.
